🛡️ About PhishGuard
PhishGuard is an educational phishing URL detection and risk analysis system combining rule-based analysis with machine learning.

The system analyzes URL characteristics, calculates a security risk score and uses a Random Forest model to provide an additional machine-learning prediction.
